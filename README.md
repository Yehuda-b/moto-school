# בית ספר לרכיבה — משחק לימוד רכיבה על אופנוע (Three.js)

## הרצה

```bash
node server.js
```

ואז לפתוח בדפדפן: http://localhost:5173

(Three.js נטען מ-CDN, לכן צריך חיבור לאינטרנט.)

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `js/main.js` | אתחול, הגדרות, זרימת המסכים, מצלמה ולולאת המשחק |
| `js/bike.js` | פיזיקת האופנוע (מצמד, הילוכים, סל"ד, היגוי, הטיה) והמודל התלת-ממדי |
| `js/world.js` | העולם: מגרש אימונים, כביש טבעת, בניינים, עצים, תמרורים ורמזור |
| `js/lessons.js` | הגדרת השיעורים: שלבים, בדיקות וטעויות |
| `js/session.js` | מנוע השיעור: ניקוד, טעויות, קונוסים, יעדים |
| `js/ui.js` | תפריטים בסגנון משחק: מחסנית מסכים, ניווט מקלדת/עכבר, מסך הגדרות עם לשוניות וחלון אישור |
| `js/hud.js` | לוח מחוונים, רשימת משימות, הודעות ומפה קטנה |
| `js/audio.js` | צליל מנוע מסונתז (WebAudio) |

## בדיקות מהקונסול

`__moto.advance(שניות)` מריץ את הסימולציה קדימה, ו-`__moto.session` מחזיר את מצב השיעור הנוכחי.
